## Facts verified
- Cookies (MDN `Set-Cookie`, fetched 2026-09-21): `SameSite=None` requires `Secure`; `Lax` sends cross-site only on top-level navigations with safe methods, never on `fetch`; some browsers default to `Lax`; `Secure` requirements are ignored on `localhost`. Third-party cookie status (MDN "Third-party cookies"): Safari's ITP blocks them by default, Firefox partitions them (Total Cookie Protection), Chrome doesn't block by default.
- Public Suffix List (downloaded from publicsuffix.org): `vercel.app`, `onrender.com`, `netlify.app`, `herokuapp.com`, `github.io`, `up.railway.app` are all public suffixes, so two projects on one of them are different sites.
- `cors` package (expressjs.com middleware page): default `origin: "*"`, methods `GET,HEAD,PUT,PATCH,POST,DELETE`, `allowedHeaders` defaults to reflecting `Access-Control-Request-Headers`, a RegExp origin reflects any matching origin (their own example `/example\.com$/`), and the "CORS is not access control" misconceptions section.
- Fetch/CORS rules used in the challenge (Fetch standard, as summarized on MDN): safelisted methods and headers, `Content-Type` safelist, wildcard `*` invalid with credentials, `Authorization` never covered by `Access-Control-Allow-Headers: *`, simple requests are sent even when the response is blocked.
- Mongoose (docs for v9.10.1, `npm view mongoose` latest 9.10.1): `maxPoolSize` default 100, `bufferTimeoutMS` default 10000, `serverSelectionTimeoutMS` default 30000; `unique` is not a validator; update validators off unless `runValidators`; lean docs skip getters, virtuals and transforms (~3x smaller); `select: false`; populate uses one query per path; `autoIndex` recommended off in production; Mongoose 9 pre middleware no longer receives `next()` (migrating_to_9).
- MongoDB: Atlas access list up to 200 entries, temporary entries up to 7 days, peering and private endpoints; Node driver `maxPoolSize` 100.
- Express 5 (`npm view express` latest 5.2.1): rejected promises go to error middleware; `/*splat` and `/{*splat}` replace `*` (migration guide); `res.sendfile()` removed. `express-session` needs `trust proxy` for `secure: true` behind a proxy (middleware docs).
- Render (render.com/docs/free): free web services spin down after 15 minutes idle, take about a minute to spin up, and have an ephemeral filesystem; outbound traffic uses published regional IP ranges.
- Challenge expectations: every CORS/cookie test case was derived by hand first and then checked against the reference solution (18/18 agreed). The refresh coordinator was checked against three mutants (no stale-token check, no waiting during refresh, logout on network error); each fails exactly the test aimed at it.
