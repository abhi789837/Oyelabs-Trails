## Facts verified
- VS Code settings precedence (language-specific scopes after all plain scopes; objects merged, primitives/arrays replaced), `codeActionsOnSave` values `explicit`/`always`/`never` (booleans still valid, being deprecated), Restricted Mode disables AI agents, terminal, tasks, debugging, workspace settings, extensions: code.visualstudio.com docs (settings, refactoring, workspace-trust).
- Git: reflog expiry 90 days / 30 days unreachable (git-reflog); `bisect run` exit codes 0 / 1–127 except 125 / 125 skip / others abort (git-bisect); `--force-if-includes` and background-fetch caveat (git-push); merge base definition, `--all`, `ort` merges multiple bases into a virtual base (git-merge-base, merge-strategies); during rebase "ours" is the upstream side (git-rebase); `git branch -d` rules (git-branch).
- GitHub: rebase and merge always creates new SHAs and committer info; squash drawbacks (about-merge-methods); branch protection blocks force pushes/deletion by default and doesn't bind admins by default; stale-approval dismissal is optional (about-protected-branches); unspecified `permissions` become `none` (workflow syntax); fork runs get no secrets and a read-only token, `pull_request_target` runs in the default-branch context (events-that-trigger-workflows); PR caches scoped to `refs/pull/<n>/merge`, no child/sibling access, low-trust triggers get read-only default-branch cache access (dependency-caching reference, 2026).
- npm: `npm ci` semantics (npm-ci.md); caret and prerelease rules (node-semver README); peers installed since npm 7, `overrides` root-only (package-json.md); npm 11.5.0 (Jul 2025) OIDC trusted publishing; 11.10.0 (Feb 2026) `min-release-age`; npm 12.0.0 (2026-07-08) blocks dependency install scripts unless approved in `allowScripts`, `allow-git`/`allow-remote` default `none`, `npm-shrinkwrap.json` dropped (CHANGELOG, npm-install-scripts.md). Latest npm is 12.0.2, but Node 24.21.0 and 26.9.0 bundle npm 11.19.x (nodejs.org/dist/index.json).
- Vite: 8.0 released 2026-03-12 with Rolldown for dev pre-bundling and builds, Oxc transforms, compatibility layer for `esbuild`/`rollupOptions`, full bundle mode experimental (announcing-vite8); docs at v8.3.0; pre-bundled deps cached `max-age=31536000,immutable` (dep-pre-bundling); env priority, `VITE_` prefix, strings, `%VAR%` HTML replacement ignoring unknowns, mode vs NODE_ENV table (env-and-mode); HMR boundaries (api-hmr); transpile-only TypeScript (features).
- DevTools: live metrics screen, CPU throttling relative to your machine with calibration (performance reference); snapshots start with GC, shallow vs retained size, "Objects retained by detached nodes" and console-retained filters, detached subtree example (heap-snapshots); coverage per function / per block (coverage); logpoints, conditional and DOM breakpoints, `debug(fn)` (breakpoints).
