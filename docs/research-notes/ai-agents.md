## Facts verified
- MCP 2026-07-28 changelog and spec: sessions and `Mcp-Session-Id` removed; no `initialize` handshake, protocol version and client capabilities in every request's `_meta`; mandatory `server/discover`; `subscriptions/listen` replaces the GET stream and `resources/subscribe`; multi round-trip requests (`input_required`) replace server-initiated requests; Tasks moved to an extension; SSE resumability removed (broken streams must be re-issued with a new id); Roots, Sampling and Logging deprecated (use provider APIs instead of Sampling); HTTP+SSE transport and Dynamic Client Registration deprecated; deterministic `tools/list` order recommended for prompt-cache hits. Primitives: tools model-controlled, resources application-driven, prompts user-controlled; elicitation is the remaining client feature. Transports: stdio and Streamable HTTP.
- MCP tools spec: protocol errors vs tool execution errors (`isError: true`), annotations untrusted unless the server is trusted, human-in-the-loop SHOULD, clients should show tool inputs and validate results; stateful tools via explicit handles with per-call authorization. Security best practices: token passthrough forbidden (MUST NOT accept tokens not issued to the server), confused deputy, SSRF, state handle hijacking, local server compromise, scope minimization.
- Anthropic "Building effective agents": workflow patterns (prompt chaining, routing, parallelization with sectioning and voting, orchestrator-workers, evaluator-optimizer), start with direct API calls, ACI/poka-yoke tool design.
- Anthropic multi-agent research system: +90.2% vs single-agent Opus 4 on the internal eval; agents about 4x chat tokens, multi-agent about 15x; token usage explains about 80% of BrowseComp variance; poor fit for shared-context/coding tasks; effort-scaling rules in prompts.
- OpenAI Agents SDK orchestration: LLM-driven vs code-driven; agents-as-tools (manager keeps control) vs handoffs (specialist takes over). Claude Agent SDK subagents: context isolation, only the final message returns, tool restrictions, depth/concurrency/spend caps.
- Anthropic "Demystifying evals for AI agents": task/trial/grader/transcript/outcome definitions, grader types, grade outcomes over rigid paths, pass@k vs pass^k, capability vs regression evals, clean environment per trial, start with 20–50 tasks, balanced sets.
- ReAct (arXiv 2210.03629): interleaved reasoning and acting reduces CoT hallucination/error propagation; +34 and +10 points absolute success on ALFWorld and WebShop with one or two in-context examples.
- Claude handle-tool-calls doc: tool results first in the user message, `is_error`, parallel results in one message, untrusted tool-result content (indirect prompt injection). Simon Willison's lethal trifecta; OWASP LLM06:2025 Excessive Agency.
- Code challenge: the agent-loop driver records the last message the model saw on each call, so tests verify batching of parallel results, `tool_use_id` matching and that the assistant turn was appended before tool results.
