## Facts verified
- Tailwind v4.3 (2026-05-08): scrollbar utilities, `@container-size`, `zoom-*`, `tab-*`, stacked/compound `@variant`, `--default()` for functional utilities; v4.2: mauve/olive/mist/taupe palettes, `@tailwindcss/webpack`, more logical-property utilities (tailwindcss.com/blog/tailwindcss-v4-3). Docs site shows v4.3.
- Upgrade guide: renamed utilities (`shadow-sm`→`shadow-xs`, `shadow`→`shadow-sm`, same for rounded/blur/drop-shadow; `outline-none`→`outline-hidden`; `ring`→`ring-3`), border default `currentColor`, important modifier at the end, variant stacking now left to right, `bg-(--var)` replaces `bg-[--var]`, underscores instead of commas in grid arbitrary values, `hover` wrapped in `@media (hover: hover)`, `@layer utilities/components` no longer register utilities (use `@utility`), JS config only via `@config`, `corePlugins`/`safelist`/`separator` unsupported, `@reference` for Vue/Svelte/CSS modules, `theme()` deprecated.
- Theme variables, namespaces, `--*: initial`, `@theme inline`, `@theme static` (docs/theme); `@source`, `@source not`, `source(none)`, `@source inline()` and skipped files (docs/detecting-classes-in-source-files); dark mode default media query and `@custom-variant dark (&:where(.dark, .dark *))` (docs/dark-mode); container query sizes and `@container-size` (docs/responsive-design); `@plugin` listed under compatibility, CSS wins over plugins/configs (docs/functions-and-directives); plugin options in CSS blocks (tailwindcss-forms and tailwindcss-typography READMEs).
- Compiled with the real engine (tailwindcss 4.3.3 in a scratch folder): `.grid` is emitted after `.flex`; `*:bg-sky-50` compiles to `:is(.\*\:bg-sky-50 > *)` after `.bg-red-50`; `data-open:` matches `[data-open]`; `@apply card` on a `@layer components` class fails with "Cannot apply unknown utility class"; `hover:` doesn't work for `@layer utilities` classes but does for `@utility`; `--value(integer)` rejects `gutter-[3]` and `gutter-1.5`; `*:first:` vs `first:*:` selectors; `text-(--x)` is a colour and `text-(length:--x)` a font size; `:root` variables create no utilities; `@theme inline`, `@source inline()` and `dark:scheme-dark` output.
- tailwind-merge 3.7.0 supports Tailwind v4.0–v4.3 (v2.6.0 for Tailwind v3). Every expected output in the `tw-apply-vs-components` challenge was cross-checked against real `twMerge`, and the spec was aligned with it (for example, any font size overrides an earlier `leading-*`). Deliberate simplifications, stated in the instructions: variant order is always ignored, and values aren't validated (real tailwind-merge doesn't treat `my-card` as a margin).
