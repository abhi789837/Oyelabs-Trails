## Facts verified
- MongoDB manual (8.3 current): 16 MiB BSON limit; the unbounded-arrays anti-pattern with subset/reference fixes; single-document atomicity; multi-document transactions need a replica set (fCV 4.0) or sharded cluster (fCV 4.2); the default read concern is `local`; transactions default to `w: majority` since 5.0; aggregation optimizations ($match/$sort first use indexes, $sort+$limit coalescence, $lookup+$unwind coalescence, $match moved before projections); limits (100 MB per stage, spilling by default since 6.0 via `allowDiskUseByDefault`, 1000 stages, 16 MiB output documents); a `$facet` first in the pipeline does a COLLSCAN; `$unwind` drops null/missing/empty and passes non-array values through; `$sum`/`$avg` ignore non-numeric values; `$group` doesn't order its output. `$group` over empty input emits no documents: not stated on the `$group` page, but confirmed by several independent sources (it's a well-known difference from SQL).
- Mongoose 9.10.1 docs: validation is the first pre('save') hook; `unique` isn't a validator; update validators are off by default and limited to certain operators; `strictQuery: true` strips unknown filter paths; `populate` runs a separate query; lean documents are about 3x smaller and have no getters/virtuals/save. The Mongoose 9 migration guide (9.0.0 released 2025-11-21) covers: no `next()` in pre middleware, `new`/`returnOriginal` deprecated for `returnDocument`, update pipelines off by default, Node 20.19+.
- Redis docs: the eviction policy list (including `allkeys-lrm`/`volatile-lrm`, new in 8.6), `noeviction` returns errors on writes, `volatile-*` behaves like `noeviction` when no key has a TTL, `maxmemory 0` is the 64-bit default, approximated LRU/LFU. EXPIRE: SET/GETSET/*STORE clear the TTL, INCR/LPUSH/HSET keep it, passive plus active expiry, and replicas wait for the primary's DEL. Licenses page: Redis 8 is RSALv2/SSPLv1/AGPLv3; 7.4 was RSALv2/SSPLv1; 7.2 and earlier were BSD-3. Valkey: Linux Foundation fork of 7.2.4 under BSD-3 (announced 2024-03-28).
- Cache stampede sources: the Facebook memcache paper (leases), Vattani et al. VLDB 2015 (probabilistic early expiration), RFC 5861 (stale-while-revalidate).
