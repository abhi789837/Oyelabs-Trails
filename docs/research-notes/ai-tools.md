## Facts verified
- METR (Jul 2025): 16 experienced OSS developers, 246 issues; 19% slower with AI, forecast 24% faster, believed 20% faster afterwards (metr.org study page).
- Copilot: cloud agent triggered only by users with write access, pushes only to its own `copilot/` branch, can't mark ready/approve/merge, Actions workflows wait for "Approve and run workflows", hidden characters filtered (risks-and-mitigations page). Content exclusion isn't supported in VS Code Edit/Agent modes or Copilot CLI, and IDE-provided semantic info can leak (content-exclusion page). Repo instructions in `.github/copilot-instructions.md`, path-specific `.github/instructions/*.instructions.md` with `applyTo`; nearest `AGENTS.md` takes precedence.
- Cursor: 0.46 unified Chat/Composer/Agent (cursor.com/changelog/0-46-x); Composer is Cursor's RL-trained agent model since 2025-10-29 (cursor.com/blog/composer); Cursor 3 (Apr 2026) added the Agents Window; rules apply to Agent chat only, not Tab (cursor.com/docs/rules); checkpoints are local, separate from git, don't track terminal changes (cursor.com/docs/agent/overview); Plan Mode via Shift+Tab (cursor.com/docs/agent/plan-mode).
- Claude Code: agentic loop gather/act/verify, harness vs model, checkpoints only cover file edits (how-claude-code-works); explore/plan/implement/commit, skip plan if diff fits in one sentence, clear after two failed corrections, writer/reviewer pattern (best-practices); `bypassPermissions` for isolated containers/VMs only, deny rules apply in every mode (permission-modes); `claude -p --output-format json`, `--allowedTools` (best-practices).
- App builders: v0 generates Next.js/Tailwind/shadcn and deploys to Vercel (v0.app/docs); Bolt has Bolt Database/Bolt Cloud and token billing (support.bolt.new), built on StackBlitz WebContainers (stackblitz/bolt.new repo); Lovable scans can't guarantee security and recommend a professional review for sensitive data (docs.lovable.dev security overview); CVE-2025-48757: 303 endpoints across 170 of 1,645 Lovable projects with inadequate RLS, scanner checked existence not correctness (Matt Palmer's statement).
