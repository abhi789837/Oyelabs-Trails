## Facts verified
- XSS/CSP/CSRF: React `sanitizeURL.js` (React 19 replaces `javascript:` URLs with one that throws "React has blocked a javascript: URL as a security precaution."); MDN CSP guide ("If a directive contains nonce or hash expressions, then the unsafe-inline keyword is ignored"; report-only can't be set in `<meta>`); MDN `script-src` (`'strict-dynamic'` ignores allow-lists and `'unsafe-inline'`; the backwards-compatible CSP1/2/3 policy); MDN `frame-ancestors` ("not supported in the <meta> element"); MDN Trusted Types "Baseline 2026, newly available since February 2026"; MDN Set-Cookie ("Some browsers use Lax as the default"; Lax-by-default allows POSTs for cookies set within two minutes); OWASP CSRF cheat sheet (signed double-submit recommended, Fetch Metadata, SameSite as defense in depth).
- Core Web Vitals: web.dev Web Vitals (2.5 s / 200 ms / 0.1 at the 75th percentile, split by mobile/desktop); web.dev INP (clicks, taps, key presses; one highest ignored per 50 interactions; poor above 500 ms); web.dev blog "INP becomes a Core Web Vital on March 12" (replaces FID); web.dev CLS (session windows: under 1 s between shifts, 5 s cap, largest window); web.dev optimize LCP (TTFB, resource load delay, load duration, render delay). The CLS arithmetic question was worked by hand.
- Code splitting: Vite 8 build options (`build.rollupOptions` is a deprecated alias of `build.rolldownOptions`), Vite migration guide (object form of `manualChunks` removed, function form deprecated in favor of Rolldown `codeSplitting`), Rolldown automatic code splitting (modules grouped by the set of entries that import them, dynamic imports become entries) and manual code splitting docs; Vite `vite:preloadError`. The challenge solution was run against wrong variants (not taking the union of `loadedBy` for group chunks, emitting unreachable modules); each fails at least one test.
- Lazy loading: web.dev browser-level lazy loading (distance thresholds by connection), MDN `<img>` (`sizes` defaults to `100vw`; `sizes="auto"` only valid with `loading="lazy"`), react.dev `lazy` (default export required; don't declare lazy components inside components).
- Accessibility: Lighthouse accessibility score (weighted average of pass/fail audits based on axe impact, no partial credit); Deque press release (2021, 57% of issues from 2,000+ audits); GOV.UK 2017 (best tool 37%/41% of barriers, Google DevTools 17%); WebAIM Million 2026 (95.9% of home pages with detected WCAG failures, low contrast 83.9%, 56.1 errors per page).
