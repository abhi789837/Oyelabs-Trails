## Facts verified
- Server Actions (guides/server-actions, data-security, mutating-data): POST-only and reachable by direct POST; Origin vs Host CSRF check with `serverActions.allowedOrigins`; 1 MB default body limit; encrypted action IDs rotated at most every 14 days, closure encryption and `NEXT_SERVER_ACTIONS_ENCRYPTION_KEY`; unused actions eliminated; sequential client dispatch; single-roundtrip re-render on `updateTag`/`revalidatePath`/`refresh`/cookie changes/`redirect`; `revalidateTag` with a profile doesn't re-render; "Failed to find Server Action" after deploys.
- `redirect` throws `NEXT_REDIRECT`, must be called outside `try`, 303 for progressive-enhancement action submissions, 307 otherwise. The challenge's rethrow rule keys on a `digest` starting with `NEXT_`, which matches both redirect and not-found/forbidden control-flow errors.
- `revalidateTag(tag, profile)` two-argument form (single-argument deprecated), `"max"` recommended; `updateTag` only in Server Actions; `revalidatePath` behaviour in actions vs handlers.
- Route Handlers: not cached by default, `GET` opt-in via `dynamic = 'force-static'`, Cache Components behaviour, `route` vs `page` conflict, 405 for unsupported methods, automatic `OPTIONS`, `RouteContext`, don't call your own handler from a Server Component (backend-for-frontend caveats). `runtime = 'edge'` is deprecated in the current docs (route-segment-config/runtime and the "Edge Runtime Deprecated" message page).
- Proxy (file-conventions/proxy): renamed from middleware in v16.0.0, defaults to the Node.js runtime, `runtime` config not allowed, Server Functions are POSTs to the route that uses them so matchers can skip them, runs on every matched request including prefetches; auth guide recommends cookie-only optimistic checks there.
- Auth: `npm view next-auth dist-tags` shows `latest` 4.24.15 and `beta` 5.0.0-beta.32; Better Auth's 2025-09-22 announcement (Auth.js now maintained by Better Auth, new projects recommended to use Better Auth); Auth.js session strategies page (JWT default without adapter, ~4 KB cookie limit with chunking, no early revocation); deployment page (`AUTH_SECRET` the only strictly required variable, `AUTH_TRUST_HOST` inferred on Vercel, `AUTH_URL` mostly unnecessary in v5, `AUTH_REDIRECT_PROXY_URL` for previews with a shared secret); edge-compatibility page (split config may be unnecessary on Next.js 16). Cache Components auth guide: `cookies()` inside plain `'use cache'` throws; pass the user ID in or use `'use cache: private'`. Vercel's postmortem: CVE-2025-29927 via `x-middleware-subrequest`, fixed in 14.2.25 and 15.2.3, self-hosted `next start`/standalone affected, Vercel not.
- Prisma ORM 7 (upgrade guide, connection docs, changelog v7.0.0 2025-11-19): driver adapters required, `prisma-client` generator with required `output`, env vars not loaded by the CLI, `prisma.config.ts`, `pg` adapter defaults (`max` 10, `connectionTimeoutMillis` 0, `idleTimeoutMillis` 10 s) vs v6 URL parameters, no URL pool parameters in v7, PgBouncer with a direct URL for the CLI, standalone Accelerate retiring 2026-12-01, Vercel dependency caching needing `prisma generate` in the build.
- Vercel (docs fetched as Markdown): 4.5 MB body limit with `413 FUNCTION_PAYLOAD_TOO_LARGE`; 300 s default duration with Fluid (Hobby max 300 s, Pro/Enterprise 800 s); default region `iad1`; Fluid compute default for new projects since 2025-04-23, in-function concurrency, bytecode caching on production only, error isolation; `attachDatabasePool`; connection-pooling KB (avoid a max pool size of 1); env var changes apply only to new deployments, branch-specific preview overrides; `VERCEL_ENV`, `VERCEL_URL`, `VERCEL_PROJECT_PRODUCTION_URL` semantics; dynamic egress IPs unless Static IPs/Secure Compute. Next.js env docs: `NEXT_PUBLIC_` inlined at build time, dynamic lookups not inlined, `NODE_ENV` is `production` for every command except `next dev`. `after()` works in Server Components, Server Functions, Route Handlers and Proxy.
- The Server Action challenge's 13 expectations were written by hand and then run against the reference solution; the untouched starter fails all 13.
