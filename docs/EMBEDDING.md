# Reference previews: which sites allow embedding

Generated by `npm run content:embeds` on 2026-09-23. 2441 reference URLs checked: 1092 can be previewed inline, 1349 can't.

The sweep also reported 7 URLs as unreachable. **None of them is a dead link** — five are
`laravel.com` pages that returned 429 because this sweep requested 157 URLs from that host in
quick succession, and two (`cseweb.ucsd.edu`, `platform.claude.com`) were transient and returned
200 on an individual retry. All seven fall back to a link card, which is what they would get
anyway, since `laravel.com` sends `X-Frame-Options: SAMEORIGIN`. Expect the same five if you
re-run this soon after hitting `laravel.com`.

Sites that send `X-Frame-Options` (DENY/SAMEORIGIN) or a restrictive CSP `frame-ancestors` can't be shown inside another site. Browsers still fire the iframe's `load` event for those blocked frames, so the app relies on this header check: blocked sites get a link card, allowed sites get an inline preview (with a timeout fallback).
